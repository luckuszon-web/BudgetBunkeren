Nøgler til notifikationer

Nøglerne laves her på din egen enhed og sendes ingen steder hen. Du skal kun gøre det én gang.

1. VAPID_PUBLIC_KEY

…

2. VAPID_PRIVATE_KEY (hemmelig)

…
  1. Supabase → Edge Functions → Secrets → tilføj VAPID_PUBLIC_KEY og VAPID_PRIVATE_KEY med værdierne ovenfor.
  2. Valgfrit: VAPID_SUBJECT = mailto:din@mail.dk (så push-tjenesten kan kontakte dig ved problemer).
  3. Kør databaseopdateringen (opdater.html), hvis du ikke allerede har gjort det.
  4. Åbn appen → Indstillinger → Notifikationer → slå til. På iPhone skal appen først være lagt på hjemmeskærmen.

Laver du nye nøgler senere, skal notifikationer slås til igen på hver enhed.
