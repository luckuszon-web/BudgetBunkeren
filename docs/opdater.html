Opdater databasen

  1. Tryk på Kopiér SQL herunder.
  2. Åbn Supabase SQL Editor (logger du ind, så kom tilbage til linket bagefter).
  3. Hold fingeren i det tomme felt, vælg Sæt ind, og tryk Run.
  4. Når der står Success, så gå tilbage til budget-siden og genindlæs den.
